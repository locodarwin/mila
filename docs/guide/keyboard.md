# Keyboard shortcuts

Most of Mila can be done from the keyboard. This page lists the keys as they come out of the box. Help, Keyboard shortcuts in the app shows your own.

`?` or `Ctrl+/` opens a quick sheet of the keys that work anywhere and where your focus is.

## Changing keys

Settings, Keyboard lists every command. Find one by name or by key, such as `ctrl k`.

- Choose a key to replace it, or add another. A command can have up to four keys.
- A key that conflicts with something says so, and offers to swap or move it. Mila will not take keys the browser needs, such as `Ctrl+W`, and it will not use `Escape`, `Tab` or `Enter`.
- Reset beside a command puts its default keys back, and Reset all shortcuts does them all.
- Every change shows Undo.

Your keys follow you to every device.

## Single-key shortcuts

The Single-key shortcuts setting, at the top of that page, turns off the keys that work anywhere and have no `Ctrl` or `Alt`: `q`, `/`, `?`, and the `g` sequences. Turn it off if keys get pressed by accident or speech input sets them off.

Keys with `Ctrl` or `Alt`, and the keys on a focused task such as `x`, keep working. New task in the sidebar and the [command palette](search-and-palette.md) do the same jobs as the keys you lose.

## Anywhere

These work when you are not typing in a field. `Ctrl+K` and `Ctrl+.` also work while you are.

| Key | Does |
|---|---|
| `Ctrl+K` | Command palette |
| `/` | Search tasks (opens the palette) |
| `q` | Add a task |
| `?`, `Ctrl+/` | Show keyboard shortcuts |
| `g` then `i` | Go to Inbox |
| `g` then `d` | Go to My Day |
| `g` then `u` | Go to Upcoming |
| `g` then `p` | Go to Projects |
| `g` then `w` | Go to the Workspace Wiki |
| `g` then `l` | Go to Time |
| `g` then `h` | Open help |
| `Ctrl+.` | Show or hide the wiki's pages |
| `Ctrl+Z` | Undo the last change |

These have no key to begin with, and you can give them one: Open the trash, Open settings, Open preferences, Open keyboard settings, Switch to light, Switch to dark, and Follow the system light or dark.

## On a task in a list

| Key | Does |
|---|---|
| `j`, Down | Next task |
| `k`, Up | Previous task |
| `Enter` | Open the task |
| `x` | Complete or reopen |
| `t` | Add to My Day, or take out |
| `1` | Priority: urgent |
| `2` | Priority: high |
| `3` | Priority: medium |
| `4` | Priority: low |
| `0` | Priority: none |
| `Alt+Up` | Move up |
| `Alt+Down` | Move down |
| `Delete`, `Backspace` | Delete the task |
| `Space` | Select the task, or take it out of the selection |
| `Shift+J`, `Shift+Down` | Select down too |
| `Shift+K`, `Shift+Up` | Select up too |
| `Ctrl+A` | Select every task in the list |
| `Escape` | Clear the selection |

While anything is selected, `x`, `t`, the priority keys and `Delete` act on every selected task. On a board card and in a table these selecting keys work too. `Shift+Down`, `Shift+Up`, `Ctrl+A` and `Escape` are fixed; the others can be changed. See [Selecting tasks](selecting-tasks.md).

## In a table

The keys for a task in a list also work on any cell of a row.

| Key | Does |
|---|---|
| Arrow keys, `Home`, `End` | Go between cells. On a task's title, Left folds its subtasks away and Right shows them |
| `Enter` | Edit the cell, sort by the heading, or choose the summary. On a heading, `Shift+Enter` adds it to the sort. `Escape` closes a picker |
| `F2` | Rename the task |
| `Alt+Left`, `Alt+Right` | On a heading, move the column. The title column stays first |

## On a board card

| Key | Does |
|---|---|
| Arrow keys, `Home`, `End` | Go between cards |
| `Enter` | Open the card |
| `Alt+Left`, `Alt+Right` | Move the card left or right |
| `Alt+Up`, `Alt+Down` | Move the card up or down |

## On a calendar entry

| Key | Does |
|---|---|
| `Alt+Left`, `Alt+Right` | Move a day earlier or later |
| `Alt+Up`, `Alt+Down` | Move a week earlier or later |

## On a timeline bar

| Key | Does |
|---|---|
| Arrow keys, `Home`, `End` | Go between bars. Left folds a task's subtasks away and Right shows them |
| `Enter` | Open the task |
| `Alt+Left`, `Alt+Right` | Move earlier or later: a day at Day zoom, a week at Week zoom, and a month at Month and Quarter zoom |
| `Alt+Shift+Left`, `Alt+Shift+Right` | Move the due date earlier or later |

## On a wiki page

| Key | Does |
|---|---|
| `Ctrl+Alt+M` | Comment on the selected words. Select some words first. This works while you type, and can be changed |

## Anywhere on this computer

In the [desktop app](desktop-app.md) only, this works while another program is in front. It can be changed, but it must be two modifier keys and a letter, a digit or `Space`.

| Key | Does |
|---|---|
| `Ctrl+Shift+Space` | Bring Mila forward and open quick add |

## Elsewhere

These are fixed and cannot be changed.

| Key | Does |
|---|---|
| `Escape` | Close the open task or dialog |
| `Enter` | In quick add, add the task |
| `Ctrl+Enter` | Send a comment |
| Up, Down | Choose in a menu or list of results |
| `Shift+F10`, the Menu key | Open the menu of what has focus: a task, view or project. See [Right-click menus](menus.md) |
| Right, Left | In a menu, open a list one step in, such as Priority, and go back from it. `Escape` goes back too, then closes the menu |
| `Alt+Up`, `Alt+Down`, `Alt+Left`, `Alt+Right` | Move a page in the wiki's tree: up and down among its siblings, right under the page above, left out a level |
| `Alt+Up`, `Alt+Down` | Move a project or a sidebar item |
| `Alt+F10` | Go to the bar over selected words, or a wiki page's toolbar when none are selected. `Escape` goes back to the text |
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+Shift+S` | Strikethrough |
| `Ctrl+E` | Code |
| Left, Right, `Shift` with them, `Home`, `End` | On the edge between the sidebar and the task panel, resize. `Shift` takes bigger steps, `Home` and `End` go narrowest and widest |
| Arrow keys, `Shift` with them | Move the picture you are cropping. `Shift` takes bigger steps |
| `+`, `-` | Zoom the picture you are cropping |
| `Ctrl+Z` | Undo a change in the theme editor |
| `Ctrl+Shift+Z`, `Ctrl+Y` | Redo a change in the theme editor |
